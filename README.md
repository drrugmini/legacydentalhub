# Legacy Dental Hub website

Responsive static website for Legacy Dental Hub.

## Files

- `index.html` — homepage
- `international-patients.html` — international patient enquiry and visit-planning information
- `robots.txt` and `sitemap.xml` — crawl guidance and public page URLs for `legacydental.in`
- `assets/logo.jpg` — clinic logo
- `assets/dr-rugmini.jpg` — Dr. Rugmini's profile photo
- `assets/dr-nicholas-john.jpg` — Dr. Nicholas John's profile photo
- `assets/dr-rency-annie-abraham.jpg` — Dr. Rency Annie Abraham's profile photo
- `assets/dr-akshay-m-v.jpg` — Dr. Akshay M V's profile photo
- `assets/dr-anjith-augustine.jpg` — Dr. Anjith Augustine's profile photo

## Preview locally

Open `index.html` in a web browser. The international patient page is linked from the main navigation and homepage.

## Publish with GitHub Pages

1. Upload the files and `assets` folder to the root of a GitHub repository.
2. Open **Settings → Pages**.
3. Select the `main` branch and `/ (root)` as the deployment source, then save.

The site uses Google Fonts when available and includes system-font fallbacks.

The homepage includes local business structured data. Canonical and social-sharing URLs are configured for `https://legacydental.in`; make sure the domain points to this published site before submitting the sitemap in Google Search Console.
